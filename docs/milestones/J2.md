# JARVIS phase 2: memory

Goal: **FLINS remembers useful things**, only what you asked or agreed to, and can always say
where a memory came from. Architecture: `docs/JARVIS_ARCHITECTURE.md`.

## Rules
1. **Nothing is saved silently.** A memory is written when you say "remember that …", when you
   add it on the dashboard / CLI, or when FLINS asks "Should I remember that …?" and you say yes.
2. **Every memory has a source and a date** ("you told me on 11 Nov, by voice"). Listing and
   "why do you know that?" are built from the stored rows, never written by the AI.
3. **You can inspect, correct, delete and switch it off**: by voice / text, CLI and dashboard.
4. **Secrets are refused** (passwords, OTPs, PINs, card numbers). Health, legal and money
   memories are marked *sensitive*: used only when your message is about them.
5. Memories serve *your* conversation with FLINS. The WhatsApp drafter doesn't get them
   (that stays with `about_me.yaml` and tiers; revisited in phase 6).

## Pieces
| Piece | Files | Notes |
|---|---|---|
| Table | migration 0012 | `memories`: kind (semantic / episodic / relationship / task), content, source, channel, importance, confidence, privacy, created / updated / expires / last used, uses. `assistant_state` (memory on/off). |
| Store | `assistant/memory.py` | `SqlMemory`: save (dedup, secret refusal, sensitivity, kind + importance scoring), search, relevant (pinned by importance + keyword match + recency), forget, edit, expire. `CombinedMemory` adds the read-only `about_me.yaml` facts. |
| Commands | `assistant/memory_commands.py` | Fixed phrases, no AI: remember that … / remember this / forget that / forget (everything) about X / forget everything / what do you remember (about X) / why do you know that / memory on, off / forget this conversation. Deleting more than the last memory asks first. |
| Suggestions | `chat_v2`, core | The conversation model may *propose* a memory (text, kind, importance). FLINS asks you; "yes" saves exactly the text shown. Threshold and cooldown in config. It still can't save by itself, and "I'll remember that" replies are still replaced. |
| Context | `assistant/context.py` | `<memories>` block: each line with where it came from. |
| CLI | `flins memory list / add / forget <id> / edit <id> <text> / clear / on / off` | |
| Dashboard | `/memory` | list, add, edit, delete, on/off |

## Not in this phase
Embedding search (keyword scoring for now; the `embed` role is reserved), automatic episodic
memories from summaries, task memory (phase 3), using memories in WhatsApp drafts (phase 6).

## Tests
save / dedup / retrieve / correct / delete / expire; secrets refused; sensitive only when
relevant; "remember to …" is a reminder, not a memory; forget-many needs yes; memory off;
"why do you know that" names real sources; suggestion needs yes and respects the cooldown;
commands work with the AI down; no memory text in the audit log; dashboard and CLI.
