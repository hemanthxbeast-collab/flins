# M0: Skeleton

## Goal
A runnable, tested project skeleton that every later milestone builds on. No WhatsApp, no LLM, no voice.

## Scope
| Area | Files | Notes |
|---|---|---|
| Packaging | `pyproject.toml`, `.python-version`, `.gitignore`, `.env.example` | uv-managed. Python ≥3.12 (3.13 is installed locally). |
| Settings | `src/flins/settings.py`, `config/flins.example.yaml` | `flins.yaml` → `AppConfig`; secrets from `.env` via pydantic-settings. Falls back to `*.example.yaml` with a warning. |
| Levels & modes | `src/flins/core/levels.py` | `Level` IntEnum (IGNORE..AUTO), `Mode` enum, `min_level()`. |
| Policy schema | `src/flins/core/policy_schema.py` | Pydantic model of `policy.yaml`. Validates levels and durations. **Clamps** hard-NOTIFY categories and flags (invariant 7) and PAUSED → IGNORE, and returns warnings. Non-NORMAL modes must have a duration (invariant 4). `dry_run` defaults to true (invariant 12). |
| Database | `src/flins/core/db.py`, `src/flins/migrations/0001_init.sql` | aiosqlite, WAL, foreign keys, `schema_migrations` table. Every §11 table. A trigger makes `audit_log` rows impossible to UPDATE. |
| Event bus | `src/flins/core/events.py` | In-process async pub/sub, topic + `*` wildcard. A failing handler is logged and doesn't stop the others. |
| Audit | `src/flins/core/audit.py` | `AuditLog.record(actor, kind, payload)`, JSON payload. |
| CLI | `src/flins/cli.py`, `__main__.py` | argparse (stdlib, so no new dependency). `doctor` works. `run`, `stop`, `mode`, `wa pair`, `wa tail` and `skills` are stubs that say which milestone adds them and exit 2. |
| CI | `.github/workflows/ci.yml` | ruff, mypy, pytest on windows-latest. |

## Tests
- Policy: the example config loads; levels parse; money/OTP/sensitive categories and flags are clamped to NOTIFY with a warning; PAUSED is clamped to IGNORE; a missing or zero mode duration is rejected; an unknown level is rejected; `dry_run` defaults to true.
- DB: migrations create every table; running them twice is a no-op; WAL is on; updating `audit_log` fails.
- Events: topic and wildcard delivery; one failing handler doesn't block the others.
- CLI: `doctor` exits 0 on a fresh temp data dir; stubs exit 2.
- Repo hygiene: `.gitignore` covers `data/` and `.env` (invariant 11).
