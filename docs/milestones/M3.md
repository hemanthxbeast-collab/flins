# M3: AI triage, drafting, output guard, dashboard, eval set

## Goal
The pipeline runs end to end in **shadow mode**: messages are grouped into bursts, triaged by
Claude Haiku, answered by a Claude Sonnet draft or a template, checked by a deterministic
output guard (plus a Haiku red-flag check for anything that would go out unreviewed), and
shown in a local dashboard as "would send" / "would ask you". **Still nothing is sent** (M4).

## Pieces
| Piece | Files | Notes |
|---|---|---|
| LLM gateway | `llm/gateway.py`, migration `0005_llm_calls.sql` | One place for every Claude call: structured JSON output (`output_config.format`), timeout, SDK retries, Pydantic validation, refusal handling, token + cost metering per call, prompt version tag, daily budget. Backends: `AnthropicBackend` (live) and `FakeBackend` (recorded answers for tests and evals). |
| Prompts | `prompts/{triage,draft,redflag}_v1.md` | Versioned files with a front-matter header. Never inline in code. |
| Triage | `llm/triage.py` | `claude-haiku-5-5`, low effort. Category (an enum built from `policy.yaml`), urgency, flags, needs_human, injection_suspected. |
| Drafter | `llm/drafter.py` | `claude-sonnet-5-5`. Gets only allowed facts, a contact card (name, tier, tone, notes, never-mention) and the thread as untrusted data. No tools. May return no reply. |
| Red flag | `llm/redflag.py` | `claude-haiku-5-5` yes/no on drafts that would be sent without review. A second gate, not the only one. |
| Output guard | `core/guard.py` | Deterministic (SPEC §8.3): confidence, commitments, unprovided facts, phone/email/URL/long digits/money not present in the inbound text or facts, never-mention terms, length, language script, "I'm not a bot" claims, injection echoes. Failure → one level down (AUTO → DRAFT, DRAFT/AUTO_SAFE → NOTIFY). |
| Debounce | `core/debounce.py` | Quiet window 25 s, max 90 s (policy). Emergency keywords flush at once. |
| Pipeline | `core/pipeline.py` | Hard rules first. **No LLM call at all** when the deterministic ceilings already cap at NOTIFY (normal mode, paused, unknown sender, money, OTP...). That saves cost and keeps those messages away from the API. |
| Dashboard | `web/app.py`, `web/templates/*` | FastAPI + Jinja on `127.0.0.1:8765`, inside `flins run` or as `flins dashboard`. Inbox with decision traces and would-send text, contacts with tier editing, stop/resume/I'm-done buttons, duplicate-contact flags. |
| Eval | `tests/eval/build_cases.py` → `whatsapp_cases.jsonl` (≥150), `src/flins/evaluation.py`, `flins eval [--live]` | Each case records what the LLM answered, including deliberately **wrong or leaky** answers, and the maximum safe outcome. CI gate: unsafe-send rate = 0. `--live` runs the same cases against the real models. |

## Choices
- Thinking can't be switched off on Haiku 5.5 / Sonnet 5.5, so triage and red flag use effort
  `low` and drafting uses `medium`.
- **No refusal fallback.** If Claude declines to draft, FLINS treats it as "tell Hemanth"
  (NOTIFY). Rerouting a declined reply to another model would be the wrong default here.
- Prompt caching is requested on the fixed system prompts. They may be under the minimum
  cacheable size, in which case the API ignores it at no cost.
- Contacts appear to the LLM by name only, never by phone number. The thread is wrapped in
  `<untrusted_thread>`, and `<` / `>` in message text are neutralised so a message can't close the tag.
- Dashboard writes need a per-run token and a matching Host header (defends against other
  websites and DNS rebinding). It listens on 127.0.0.1 only.
- No HTMX: plain server-rendered pages with auto-refresh. No CDN or extra JS to trust.

## Tests
Gateway (validation, refusal, timeout, metering, budget), guard (table of leaks), drafter and
triage prompt building (no phone numbers, tags neutralised), debounce, pipeline (LLM skipped
when capped, guard downgrade, would-send), dashboard (pages render, writes need token and
Host, tier edit audited), eval gate, replay scenarios with recorded LLM answers.

## Demo
```powershell
uv run flins eval                 # recorded answers: unsafe-send rate must be 0
uv run flins eval --live          # needs ANTHROPIC_API_KEY; costs a few cents
uv run flins run                  # then open http://127.0.0.1:8765
```
