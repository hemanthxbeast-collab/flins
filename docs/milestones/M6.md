# M6: Voice

## Goal
Talk to FLINS: press a hotkey, say "I'm in working mood till 6", hear it answer. Natural-language
commands also work in the WhatsApp self-chat ("reply to Radhika saying I'll call at 8"), and
FLINS **confirms before any send or mode change** that came from free-form understanding.

## Pieces
| Piece | Files | Notes |
|---|---|---|
| Recording | `voice/audio.py` | `sounddevice`, 16 kHz mono. Stops after ~1.2 s of silence (simple energy check) or 12 s. |
| Speech-to-text | `voice/stt.py` | `faster-whisper`, model `base` by default (`small` for better Hinglish), int8 on CPU, downloaded on first use (~140 MB / ~460 MB). Its built-in Silero VAD trims silence, so no separate `silero-vad`/PyTorch install. |
| Text-to-speech | `voice/tts.py` | Windows' built-in voices via `pyttsx3` (offline, no download). Piper is deferred. |
| Hotkey | `voice/hotkey.py` | `pynput`, default `Ctrl+Alt+Space`: press, speak, it stops when you stop talking. Press again to cancel. |
| Voice loop | `voice/loop.py` | hotkey → beep → record → STT → command router → speak the answer. Also speaks urgent alerts and the session summary. |
| Tier-B intents | `prompts/intent_v1.md`, `core/intents.py` | LLM turns free text into a structured intent (mode, status, approve/reject/edit, send to a contact, pending, summary, unknown). Tier A (fixed phrases) is always tried first and needs no AI. |
| Confirmation | `core/commands.py` | Anything Tier B would *do* (send, change mode) is first read back: "Send to Radhika: '…'? Say yes or no." It waits 60 s. |

`voice` is an optional install (`uv sync --extra voice`), so FLINS without voice stays lean.

## Sending from a command
"Tell Mom I'll call at 7" goes to the outbox as an approved message, worded as FLINS (FLINS ≠ Hemanth):
*"Hemanth asked me to tell you: I'll call at 7. — FLINS, Hemanth's assistant"*. It's still subject
to the outbox checks: in M6, only to people who wrote to you in the last 24 h.

## Tests
Fakes for mic, STT, TTS and hotkey (no audio hardware in CI): voice loop end to end, text
cleanup for speech, Tier-B parsing with recorded answers, confirmation (yes / no / timeout /
another command in between), contact-name matching, sends always confirmed. A `flins voice test`
command measures real latency on your PC (target: speech end → readback start < 2.5 s).
